NSM.exe requires the game pack file "mp1.pack" in THIS folder
(client-new\packs\mp1.pack).

Fastest: go back to client-new\ and double-click
PUT-PACKS-IN-PLACE.bat - it downloads the pack automatically
(about 230MB, one time only).

Manual: download mp1.pack from
https://github.com/platinum-cfx/NSM/releases/download/game-packs/mp1.pack
and place it in this folder.

The pack was rebuilt from this project's own sources (mp1_extractor.cpp)
with the real libce2.dll payload; it is too large for the repo ZIP
(GitHub 100MB file limit), which is why it ships as a release download.
