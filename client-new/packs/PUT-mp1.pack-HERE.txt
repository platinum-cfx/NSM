NSM.exe requires the game pack file "mp1.pack" in THIS folder
(client-new\packs\mp1.pack). It cannot ship in the GitHub ZIP
(over GitHub's 100MB file limit) - it came with your original
NSM download.

Easiest: copy mp1.pack into client-new\ (loose next to NSM.exe),
then double-click PUT-PACKS-IN-PLACE.bat - it moves the file into
packs\ for you.
